# War Thunder 游戏聊天实时翻译助手

本项目是一个专为《战争雷霆》设计的聊天翻译工具，能够自动获取游戏内的聊天消息，通过 DeepSeek (或其他openAI) 实时翻译成中文，并以半透明、可点击穿透的窗口显示在游戏界面上。支持快捷键切换显示/隐藏，保留翻译历史记录。

## 功能特点

-  **实时抓取**：自动轮询游戏本地 API (`http://localhost:8111/gamechat`)，获取最新聊天消息。
-  **AI 翻译**：调用 DeepSeek 大模型进行上下文翻译，可以翻译简写，网络梗，等传统翻译不能使用的场景。
-  **优雅窗口**：无边框、半透明、置顶且可点击穿透，不影响游戏操作。
- ⌨️ **快捷键**：按 `F3`（可配置）隐藏/显示翻译窗口。
- 📜 **历史记录**：保留最近 20 条（可配置）翻译记录，支持滚动查看。

## 安装与配置

### 1.环境要求
- Windows 操作系统（使用了 `win32gui`、`pynput` 等库）
- Python 3.8 或更高版本
